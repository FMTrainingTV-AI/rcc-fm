# Project

Project-management scaffold for this engagement. Light by design: only the
day-one folders exist; everything else is created on first use (the taxonomy
lives in `CLAUDE.md`).

## Working the project

1. `_pm/skeleton.md` holds the outcome, journey, and non-negotiables —
   written at scaffold time; keep it current as scope moves.
2. Use `discovery` when the outcome or scope still needs clarification; a
   clear request goes straight to work.
3. Open each session with `whats-next`; close it with `stepping-away`.
4. Work items live in `docs/TASKS.md` (Current / Next / Done) unless
   `CLAUDE.md` names another tracker. Decisions go to `docs/adr/` when they
   need a durable separate record. Tiny implementation steps don't need items.
5. Two or three independent items can run side by side as sibling sessions.

Stamped by the pm plugin's `/pm:pm-scaffold` (`FMTrainingTV-AI/rcc-fm`).
The workflow of record is that plugin's `SDLC.md`.
