# Tasks

The task list for this project — the tracker of record unless `CLAUDE.md`
names another. Work items only: loose ideas go to `docs/intent/inbox.md`,
decisions to `docs/adr/`.

`whats-next` reads **Current** and **Next** as the frontier and moves the
pick-up into **Current**. `stepping-away` moves verified work to **Done** with
the date and its evidence, and adds new work to **Next** after checking it
isn't already listed. An item that needs an answer carries
`Waiting on: <who> — <what> (since YYYY-MM-DD)` and isn't picked up until the
answer lands.

Format: `- [ ] <item> — <intent or source, if any>` · done:
`- [x] YYYY-MM-DD <item> — <evidence>`
